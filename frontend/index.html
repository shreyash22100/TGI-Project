Architecture

      
How this project's CPU/demo mode maps to real TGI's architecture.


      


      
Real TGI (Docker + GPU)

      
User → Router (Rust, request queueing + continuous-batching scheduler) → Launcher-managed Model Server(s) (Python/PyTorch, optionally tensor-parallel across multiple GPUs via NCCL) → LLM → streamed tokens back to User.


      
This Project's Demo Mode

      
User → FastAPI app (plays the role of Router + Launcher) → model_service.py (plays the role of the Model Server) → Hugging Face Transformers model on CPU → streamed tokens back to User.
